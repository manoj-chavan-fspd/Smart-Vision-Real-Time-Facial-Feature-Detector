# 👁️ Smart Vision: Real-Time Facial Feature Detector

A real-time computer vision application built with **OpenCV**, **Haar Cascade Classifiers**, and **Streamlit** to detect key facial features (Face, Eyes, Eyeglasses, and Smile) via web camera or video input.

---

## ✨ Features

* **Real-time Face Detection:** Detects human faces in real-time.
* **Eye & Glasses Detection:** Identifies eyes and tracks eyeglasses accurately using Haar Cascades.
* **Smile Detection:** Captures smiles with instant visual feedback.
* **Interactive UI:** Built using **Streamlit** for a smooth, user-friendly web interface.

---

## 🛠️ Tech Stack & Requirements

* **Language:** Python
* **Libraries:** 
  * `opencv-python`
  * `streamlit`
  * `numpy`
